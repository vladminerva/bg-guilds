BG Guilds: shows the guild of every player on the battleground scoreboard (WotLK 3.3.5a, Warmane).

Install (once):
1. Unzip these files into your WoW folder, the one with Wow.exe in it.
2. Double-click install-updater.bat. If Windows shows a security warning, click "Run" or "More info" > "Run anyway".
3. In game, tick "BG Guilds" and "BG Guilds - Data" in the AddOns list. Type /bgg demo to see it.

Updates:
Every time you log in to Windows, the updater checks for new guild data and installs it in a second or two.
It only ever touches Interface\AddOns\BGGuilds and Interface\AddOns\BGGuilds_Data. No admin rights needed.

Remove the updater: double-click uninstall-updater.bat.
Log file: %APPDATA%\BGGuilds\update.log
